## 项目依赖如何管理

- 后端依赖写在 `backend/pom.xml`，构建时通过 `backend/maven-settings.xml` 使用 DevTools 中的 Maven 缓存。
- 前端依赖写在 `monitor-web/package.json`，安装后生成的 `node_modules` 只放在项目目录并被 Git 忽略。
- Python 采集器默认只使用标准库；需要更完整的系统指标时，再根据 `collector/requirements.txt` 安装 `psutil`。
- MySQL、MongoDB、Redis、RabbitMQ 由 `docker-compose.yml` 管理，后续启动容器时由 Docker 拉取镜像；MongoDB Compass 使用本机 `27019` 端口连接。
- Docker Profile 已配置 MySQL JDBC 连接、初始化表结构和 Redis 连接；本地默认配置仍会在数据库不可用时使用内存存储。
- Docker Profile 同时启用 RabbitMQ 告警交换机、队列和消费者；异常指标按服务器设置 5 分钟冷却时间，避免重复告警。
- k6 v2.3.0 已按需下载到 `D:\DevTools\k6-v2.3.0`，不放入项目目录；压测目标仅使用本机 Docker 网关。

